# AI Company

사용자는 PM과 목표·완료 조건을 정하고, 개발·검사·독립 검수·수정·보고가 이어지는 작업 시스템을 구축합니다. 실행 조건과 역할을 관리하는 하네스와 작업 완료까지 이어지는 루프를 함께 만듭니다.

**[현재 작업 현황](docs/review/index.md)**에서 지금 단계·최근 완료·차단 사유·다음 행동을 확인하세요.

| 찾는 내용 | 문서 |
| --- | --- |
| 지금 어디까지 진행됐는가 | [현재 작업 현황](docs/review/index.md) |
| 시스템이 어떻게 구성되고 작업하는가 | [운영·개발 매뉴얼](docs/review/manual.md) |
| 작업별 검수·판단 원문 | [검수 기록 목록](docs/work-reviews/README.md) |
| 같은 주소로 최신 내용을 확인하는 방법 | [고정 주소·갱신 명세](docs/review/publishing.md) |
| 개발 설정·작업 묶음·검사 효율 | [서버 Codex 개발 효율](docs/work-reviews/server-codex-efficiency-policy.md) |

현재 현황은 한 곳에서 갱신하고, 과거 판단은 커밋에 고정한 기록으로 남깁니다. 구현·자동 검사·실제 검수·설치·운영 전환을 별도로 표시하며 서버 보고와 직접 확인을 구분합니다.

일상 확인용 제안 주소는 `hyungwon.cloud/review`입니다. **도메인 페이지는 아직 배포하지 않았습니다.** 준비 전에는 위 Git 문서의 고정 경로를 사용합니다.

문서 정리는 [열린 문서 PR #23](https://github.com/HyungwonPark/ai-company/pull/23)에서 진행합니다. 제품 후보의 적용·병합 완료를 뜻하지 않습니다. 문서 재구성 전의 단계별 설명과 상태는 [2026-09-29 README 기록](https://github.com/HyungwonPark/ai-company/blob/9d444112bf0a23c3d7eaedb8c8893ed2084bb698/README.md)에 보존했습니다.
