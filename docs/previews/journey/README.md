압축을 풀고 `AI-Company-journey.html`을 Chrome에서 엽니다. GitHub 로그인·운영 로그인 없이 여는 읽기용 제품 미리보기입니다. 파일 앱의 간이 미리보기에서는 JavaScript가 제한될 수 있습니다.

1. 프로젝트를 선택하고 `계획 → 진행 → 승인 → 결과`를 오갑니다.
2. `진행`에서 최근/이전 실행, 역할·전달선·자기 이관·반환을 선택합니다. `대상 정보`와 같은 실행의 결과·승인을 대조합니다.
3. Light/Black, 전체 보기·이동·확대, 상세 닫기, 뒤로가기·새로고침을 확인합니다.

공개 합성 자료이며 운영 기록이 아닙니다. 실제 제품 JS/CSS를 묶었으나 GET 응답은 고정 자료입니다. 목표·메시지 전송, 명세 저장, 계획 확정, 후보 결정, 외부 링크·모델·서비스워커는 실행하지 않습니다. 실제 인증·읽기·쓰기·상태·서비스워커 검증은 별도 임시 API·SQLite·격리 Chrome에서 수행했습니다. 시계·기한·승인 원문을 바꾸지 않으므로 시간이 지나 만료된 시험 승인도 그대로 보이며, 모든 미리보기 쓰기는 405로 거부합니다.
