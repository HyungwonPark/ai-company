# AI Company 순서형 미리보기

ZIP을 내려받아 압축을 풀고 `AI-Company-journey.html`을 Chrome에서 엽니다. GitHub 로그인·설치·운영 로그인이 필요 없는 읽기용 제품 미리보기입니다. ZIP 내부 파일을 파일 앱의 간이 미리보기로 열면 JavaScript가 제한될 수 있으므로 브라우저에서 여세요.

1. 프로젝트를 선택하고 `계획 → 진행 → 승인 → 결과`를 오갑니다.
2. `진행`에서 최근/이전 실행을 선택하고 역할·전달선·자기 이관·반환을 누릅니다. 화면의 실행 번호와 `대상 정보`를 대조합니다.
3. Light/Black 전환, 그래프 전체 보기·이동·확대, 도움말·상세 닫기, 뒤로가기와 새로고침을 확인합니다.

공개 합성 자료이며 운영 기록이 아닙니다. 실제 제품 JS/CSS를 묶었지만 GET 응답은 고정 자료입니다. 목표·메시지 전송, 명세 저장, 계획 확정, 후보 결정, 외부 링크·모델·서비스워커는 실행하지 않습니다. 실제 쓰기 검증은 별도의 임시 API·SQLite에서 수행한 CI 기록을 참고하세요. 시계나 만료를 되돌리지 않으므로 시간이 지나 만료된 시험 승인도 그대로 표시합니다.

제품: `d46136da9108608e7bdce6bdbfb0da35e825126a`  
검사: `6a366e69909b204881cc1d0a547a7b5cd06173ee`  
검증 실행: https://github.com/HyungwonPark/ai-company/actions/runs/35905379886

HTML은 위 CI가 실제 검사한 파일 그대로입니다. manifest의 `source_commit`은 CI의 PR 합성 merge checkout `b3d155c1100b5b1386e399e5becaab1b331fb6d9`이며 PR head와 다릅니다. 29개 원본 파일 SHA-256이 제품 커밋과 모두 일치함을 별도로 확인했습니다. 이름이 같은 다른 CI의 HTML로 바꾸지 마세요.

`SHA256SUMS`로 파일을 확인할 수 있습니다. Linux/macOS: `sha256sum -c SHA256SUMS` (macOS에서는 `shasum -a 256`). Windows PowerShell: `Get-FileHash .\AI-Company-journey.html -Algorithm SHA256`.
