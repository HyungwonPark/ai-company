# 업무 중심 작업실 시안

같은 한국어 업무로 **순서형**과 **한눈형**을 비교합니다. 순서형이 현재 추천이며 최종 선택을 대신하지 않습니다. 기존 A/B/C 시안과 운영 그래프는 그대로 둡니다.

운영 API·worker·모델·승인과 연결하지 않는 예시입니다. 시안의 새 프로젝트는 탭당 1개이며, 두 번째 생성 버튼은 기존 입력과 확정을 보존해 다시 엽니다. 입력은 이 탭의 `sessionStorage`에만 보관합니다.

## 열기

```bash
python3 scripts/package_task_workspace.py /tmp/AI-Company-task-workspace.html
```

생성한 HTML을 브라우저로 열면 서버나 로그인 없이 작동합니다. CI의 `workspace-preview` 산출물에도 같은 파일을 넣습니다. source `index.html`을 직접 열어도 됩니다. 이 시안에는 개인 정보나 운영 목표를 입력하지 마세요.

## 비교할 조작

1. `모바일 로그인 정리` → `진행`에서 두 업무와 선행 조건을 선택합니다. `팀`·`기록`은 같은 실행의 다른 보기입니다.
2. 개발 업무 → `이관 예시 보기` → `기록`에서 같은 업무가 유지되는지 확인합니다. `실행`을 이전으로 바꾸면 이전 담당·결과를 읽습니다.
3. 이전 실행의 `결과` → `승인` → `후보 검토`에서 실행·후보·digest를 대조합니다. 예시 선택은 원래 `pending`을 바꾸지 않습니다.
4. `새 프로젝트`에서 이름·자연어 목표 → `PM과 시작` → `명세 저장` → `새 계획 요청` → `계획 검토`를 눌러 봅니다. 모델 호출은 없으며 명시적인 예시 확정 전 실행 수는 0입니다.
5. `순서형`과 `한눈형`, Light/Black을 바꾸어 같은 정보를 비교합니다. `비교`를 펼치면 빈 목록·연결 끊김·긴 이름·모두 대기·실패 상태를 볼 수 있습니다.

브라우저 조작 검사는 초보 사용자 사용성 시험이나 실기기 APK 검증이 아닙니다. 현재 운영 pilot 범위·예산·공유 한도·승인·PR #10 상태를 바꾸지 않습니다.
