## 구현

실행 연결 코드는 `a90ae7333c7fe515d69e61d5c1e1ce027bdd7d0b`다. 새 `cli_configuration_v2` 정책을 명시한 작업에서만 Claude 파일 실행기를 사용한다. 기존 `runtime_metadata`·`cli_configuration`의 판정과 digest를 유지한다. 기존 작업의 정책을 바꿔 통과시키지 않는다.

- Claude 개발은 기존 실행기가 커밋하는 **contribution 범위와 개별 파일 경로**로 제한한다. 디렉터리·glob·숨김 경로, 일반 full 개발의 Git·Bash 권한은 추가하지 않는다. 별도 읽기 전용 역할에는 읽기 도구만 제공한다.
- CLI `2.1.270`, 실행 파일 SHA-256, 기존 bwrap·AppArmor 프로필과 두 userns 제한값 `1`을 확인한다. socat은 명시한 경로의 검증된 실행 파일만 사용한다. 패키지·전역 PATH·프로필·권한·운영 환경은 변경하지 않는다.
- 모델 요청을 보내기 전에 실제 `get_settings`의 `applied`를 확인하고 종료 뒤 다시 확인한다. Opus 5·xhigh·Ultracode와 실제 API 요청의 모델·effort가 일치해야 한다. 모델이 쓴 설명이나 지원 목록으로 대신하지 않는다.
- 영속 RUNNING 사실에서 작업·실행·세대·시도·원본 명세·정책·입력 저장소·이전 세션을 묶는다. 제어 응답, 해당 시도의 무작위 loopback 수집기, 파일 도구의 범위·종료 기록을 대조한다. 오래된 증거, 다른 시도, 추가 도구, 충돌하는 native 메타데이터는 거부한다.
- 모델에는 파일 내용만 전달한다. 제어 설정 전체·인증 정보·원문 프롬프트를 telemetry 증거에 넣지 않는다. UI는 검증한 모델·추론 설정을 읽을 수 있고, 상세 응답에 호스트 작업 경로를 새로 공개하지 않는다.

이는 **로컬 CLI 설정·요청 관측**이다. 제공자 백엔드의 모델 신원을 암호학적으로 증명했다고 표시하지 않는다. [공식 CLI 옵션](https://code.claude.com/docs/en/cli-reference)과 [모니터링 문서](https://code.claude.com/docs/en/monitoring-usage)는 요청·관측 방식의 근거이며, 실제 적용은 각 실행 기록으로 확인했다.

## 추가로 발견한 실패

읽기 전용 시험은 CLI 비용 중단 기준을 `$0.30`으로 요청했으나 실제 종료 결과는 `$0.3924525`였다. 중단 결과를 요청 금액 이내의 엄격한 지출 보장으로 표현하지 않는다. 기본 실행기는 시도당 `$0.50` 또는 남은 정책 예산 중 작은 값을 CLI에 전달하며, 실제 보고 비용을 별도로 누적한다.

해당 세션은 소스 읽기 후 존재하지 않는 README를 요청해 거부됐고, StructuredOutput 도구에 BLOCK 내용을 보냈지만 최종 native `structured_output`은 없었다. 도구의 성공 메시지를 최종 보고로 채택하지 않았다. 추가 모델 호출로 재시도하지 않았다.

이때 기존 파서가 실패 결과의 비용을 누락하는 것도 재현됐다. 후속 수정은 **세션이 일치하는 단일 정상 native 종료 이벤트의 유효한 비용만 보존**한다. 실패 분류와 BLOCKED는 그대로이며, 잘못된 세션·손상 스트림·여러 종료 이벤트·잘못된 금액은 비용 근거로 쓰지 않는다. 기존 시험 DB는 덮어쓰지 않고 원시 로그 재처리 결과를 따로 남겼다. 전체 시험 비용은 `$0.848602`이며 읽기 전용 실패 비용을 포함한다.
