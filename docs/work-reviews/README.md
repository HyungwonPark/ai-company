## 원문과 검수 시점

위 3개 파일은 Work에서 작성한 원문을 그대로 게시한 것입니다. 원문의 날짜·검수 범위·미실시 항목을 보존했습니다. 원문 안의 “GitHub 게시를 실행하지 않는다”는 작성 당시의 범위 기록입니다. 이번 사용자의 별도 지시로 이 디렉터리의 문서 게시를 진행했습니다. 이 게시가 제품 구현·운영 적용·병합 승인을 뜻하지는 않습니다.

[PR #22](https://github.com/HyungwonPark/ai-company/pull/22)에 이미 올라간 [재설계 보충 명세](https://github.com/HyungwonPark/ai-company/blob/b31fb876a79b2548de908e295fc376bb5e451554/docs/product-experience/workspace-remodeling-spec-2026-09-23.md)는 대화로 전달받은 내용을 서버에서 정리한 별도 문서입니다. 당시 서버가 Work 원문을 읽었다는 의미로 바꾸지 않습니다. 이제 위 링크의 원문을 직접 읽고 차이와 적용 여부를 대조할 수 있습니다.

PR #22 검수 대상은 `b31fb876a79b2548de908e295fc376bb5e451554`입니다. 게시 준비 중 확인한 PR head는 `3c3c1988a5b04dcfcd7d5aacbd39fbb836bb4d95`이며, 두 커밋 사이 변경은 공개 미리보기 ZIP·해시 기록·안내 README입니다. 시안 JS·HTML·CSS의 추가 변경은 없습니다. 이후 커밋은 다시 대조하고, 과거 지적을 현재 결함으로 자동 간주하지 마세요.

검수 문서에 적힌 소스 검토·JS 상태 재현·CI 조회와 실제 브라우저·초보 사용자·APK 검증을 구별합니다. 이번 문서 게시로 새로운 화면 검증을 수행한 것은 아닙니다.

## 참조와 갱신 방법

- **시작점:** 항상 이 README에서 해당 작업 문서를 찾습니다.
- **브랜치:** 최초 게시 브랜치는 `docs/work-review-handoff`입니다. main에 병합되기 전에도 이 브랜치의 문서를 읽을 수 있습니다.
