# 작업실 명세와 검수

이 디렉터리는 마스터와 Work 검수자가 정리한 명세·검수 원문을 서버 Codex가 참조하는 곳입니다. 구현은 서버에서 진행하고, 이곳에는 요구 사항과 검수 근거를 모읍니다.

최초 게시일: 2026-09-23 · 목록 갱신: 2026-09-29 KST

**현재 단계·최근 완료·차단·다음 행동은 [작업 현황](../review/index.md)에서 확인합니다.** 시스템과 절차는 [운영·개발 매뉴얼](../review/manual.md), 고정 주소와 갱신 방식은 [페이지 게시 명세](../review/publishing.md)에 모았습니다. 이 목록은 작업별 원문과 과거 근거를 보존합니다.

## PR 완료 공통 조건

**[Claude Opus 5.5·Ultracode 필수 검수](pr-completion-review-policy.md)**를 모든 PR 완료 지시에 공통 적용합니다. 실제 별도 검수와 적용 설정·대상 패치 근거를 확인하며, 지적 수정 후에는 수정 후보를 재검수합니다. 한도·UNKNOWN 등으로 호출할 수 없으면 **Claude 검수 대기**로 남깁니다. 정적 검수 PASS를 실제 모델 검수로 대신하지 않습니다. 기존 중복 호출·공용 장부·운영 승인 조건을 유지합니다.

## 개발 효율 공통 지침

**[서버 Codex 개발 효율](server-codex-efficiency-policy.md)**을 앞으로의 구현 지시에 함께 적용합니다. 기본 Sol High, 명확한 작은 작업은 Medium/Luna, 어려운 동시성·권한·정산·복구 구간만 Extra High를 사용합니다. 한 완료 목표의 구현·검사·수정·패키징을 묶고 문맥·중복 검사를 줄입니다. 필수 Claude Opus 5.5·Ultracode 검수와 운영 승인 조건은 유지합니다. 제품 역할 모델을 바꾸는 지시는 아닙니다. **작은 수정마다 지시를 끊지 않고, 같은 목표의 관련 작업을 조금 더 넓게 묶어 조사·수정·검사·문서화·패키징까지 한 번에 마무리합니다.**

## 이전 수동 준비 지시

**[PR #36 수동 재개 준비와 한정 적용 범위](pr36-manual-preparation-scope-2026-09-28.md)**는 당시 준비·승인 범위의 기록입니다. 현재 작업은 위 R36-4 해결 확인과 한정 적용 지시를 따릅니다. [bd16563 재검수·수동 재개 원문](pr36-acceptance-manual-resume-bd16563-2026-09-28.md)의 R36-1~3 해결과 비운영 수용은 유지합니다.

- 서버는 수동 1회 명령과 비공개 실행 명세를 준비했다고 보고했습니다. Work는 현 비공개 장부·명세를 직접 확인하지 않았습니다.
- 승인 권고 범위는 고정 패키지의 신뢰 코드 4파일·대응 전환 해시·이번 PR #35 예약의 증거 기반 1회 정산·연결된 Claude 계정의 한정 COOLDOWN 조정입니다. **문서 게시를 마스터의 운영 승인으로 처리하지 않습니다.**
- 준비가 승인되어도 모델 호출은 0건으로 유지합니다. 2026-09-28 02:00 KST 이후 조건을 확인하고 사용자가 별도로 재개를 요청하면 한 번 실행합니다. READY에서 호출하는 tick은 읽기 전용 점검이 아닙니다.
- 전용 자동 재개 timer는 제외합니다. 두 worker 중지·과거 E2 hold_unknown·기존 quota timer·E1 PASS·기록·서비스·PR #10 pending을 보존합니다.
- 실제 Claude 최종 검수는 미완료입니다. 제품의 자동 대기·이관 목표와 이번 수동 PR 검수 운영 방식을 구분합니다.

Work의 GitHub 상태 확인은 읽기·알림입니다. 문서 게시가 운영 승인이나 서버 착수를 뜻하지 않습니다.
