현재 코드 커밋으로 웹 이미지를 교체할 필요는 없다. 공용 장부를 실제 호출 경로에 연결하려면 PM·조정기 및 번역 worker의 **동일 코드 버전 교체**, 비공개 장부 경로와 실행 카탈로그의 대조, 신뢰 경로의 Claude 검수기 파일 교체가 한 번의 검토된 적용 단위다. 장부는 기존 스키마 2이며 새 테이블이 없다. 기존 장부·원본 호출 기록·승인·사용량은 보존한다.
