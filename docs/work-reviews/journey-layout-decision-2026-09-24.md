# 순서형 기본 배치 선택과 다음 작업

기록일: 2026-09-24 KST · 버전: 1.0

## 결정

**순서형을 기본 설계 방향으로 선택합니다.** 마스터가 이 대화에서 “순서형이 나아보이네”라고 답한 것을 근거로 기록합니다. 순서형·한눈형 중 다시 선택하도록 묻거나 비교 양식 작성을 진행의 선행 조건으로 두지 않습니다.

이 선택이 모든 세부 화면·문구·그래프 동작까지 확정했다는 뜻은 아닙니다. 선택 이유, 사용한 기기·테마, 과제별 이해도·조작 결과는 전달받지 않았으므로 채워 넣지 않습니다. 별도 초보 사용자 검증·APK 확인·제품 연결·운영 배포의 완료나 승인을 이 답변으로 만들지 않습니다.

대화에서 비교 대상으로 안내한 후보는 PR #22 게시 `4ffd4e702ea2f125569c3f410328a57d3976fc84`, 시안 소스 `c8f10ba61551be2e75e139c9538f20b8030846b2`입니다. 해당 후보의 [F1·F2 재검수](ai-company-pr22-review-4ffd4e7-2026-09-24.md)는 보존합니다. 이후 후보가 바뀌면 현재 코드와 차이를 대조합니다.

## 제품 연결에서 유지할 방향

1. **주 동선:** 프로젝트 → 계획 → 진행 → 승인 → 결과. 단계명과 현재 위치를 일관되게 보여 주고 그때 필요한 행동을 우선합니다.
2. **계획:** PM과 목표·범위·완료 조건을 정하고 마스터의 명시적인 계획 확정 뒤 실행합니다. 저장·계획 준비·직접 확정의 기록은 구별합니다.
3. **진행:** 무엇을 하는지·왜 기다리는지·다음에 무엇이 필요한지를 먼저 보여 줍니다. 업무·팀·기록을 나누고 역할·모델·실제 이관 근거는 맥락에 맞게 열람합니다.
4. **승인과 결과:** 승인 요청을 진행과 별도로 찾을 수 있게 유지합니다. 여러 실행의 미처리 요청은 발견할 수 있어야 하며, 선택한 요청의 프로젝트·계획·실행·후보 연결은 정확해야 합니다.
5. **한국어·모바일:** Light·Black과 모바일 동선을 보존합니다. 내부 식별자·해시·경로는 상세 근거에 두고 필요한 설명은 짧은 한국어로 씁니다. 원문·번역·승인 권한은 유지합니다.

순서형은 화면 탐색 방식입니다. **개발·검사 등 실제 업무를 직렬 실행으로 바꾸는 결정이 아닙니다.** 독립 업무의 병렬 실행, 한도 대기·적격 담당 이관, 재개·중복 방지와 기존 예산·권한 정책을 보존합니다.

한눈형의 비교 자료는 보존합니다. 이를 운영 제품의 추가 유지 기능으로 반드시 구현하거나 반대로 기존 파일을 삭제하라는 결정은 하지 않았습니다.

## 서버에서 작성할 연결 계획

현재 제품 코드를 먼저 확인하고, 시안의 각 부분을 실제 기능과 연결하는 표를 작성합니다. 시안 HTML을 그대로 운영 화면에 덮어쓰지 않습니다.

| 화면 | 계획에 밝혀야 할 연결 |
| --- | --- |
| 프로젝트 | 실제 목록·목표·최근 변화·미처리 요청의 출처 |
| 계획 | 기존 PM 대화·계획 버전·직접 확정 경로와 준비·실패 상태 |
| 진행 | 조회 응답의 업무·역할·모델·대기·이관 및 갱신·선택 상태 |
| 승인 | 기존 승인 처리와 정확한 대상 연결, 권한·중복 처리 |
| 결과 | 같은 실행의 완료·남은 일·차단·다음 행동과 근거 |

각 항목에 현재 파일·데이터 출처·재사용할 동작·필요한 변경·검증 방법을 붙입니다. 실제 기록이 없는 부분을 예시 성공·예시 계획·가짜 진행으로 채우지 않습니다. 시안의 “단계 재생”·고정 후보·로컬 예시 결정은 제품 기능과 구별합니다.

첫 구현 구간은 선택한 순서형의 기존 프로젝트 탐색과 같은 실행의 진행·결과 조회를 연결하는 구간을 우선 제안합니다. 이후 PM 계획·명시적 확정·승인 조작을 기존 계약에 맞게 연결합니다. 이는 다음 계획의 분할 제안이며 이미 구현·연결됐다는 보고가 아닙니다.

업무 중심의 기본 보기를 채택해도 관계·역할·이관 이력을 삭제하지 않습니다. 제품 그래프를 재사용·수정·다른 보기로 옮기는 항목마다 기존 기능과 대체 검증을 대응시킵니다. 시안의 단순한 CSS 흐름도를 기존 그래프의 수정 완료 근거로 사용하지 않습니다.

기존 실행 엔진과 저장된 기록을 우선 재사용합니다. 이번 배치 선택을 ComfyUI·새 그래프 엔진·새 모델 연결 도입 결정으로 확대하지 않습니다.

## 검수와 진행 기준

- 같은 실행의 화면 이동·보고·승인 대상 연결, 입력·선택·화면 위치 보존을 확인합니다.
- Light·Black과 320/390/1440px, 실제 클릭·키보드·모바일 조작의 영향을 변경 범위에 맞춰 검증합니다.
- 시안 검사, 실제 API와 연결한 비운영 검증, APK 실기기, 운영 적용을 각각 구별해 보고합니다.
- 상세 사용자 의견과 초보 사용자 관찰은 이후 개선 근거로 받을 수 있습니다. 아직 없는 결과를 합격 근거로 만들지 않되, 이미 받은 기본 방향 선택을 다시 대기 상태로 돌리지 않습니다.
- 검토 가능한 비운영 후보와 적용·복구 범위를 구체화합니다. 운영 웹·worker·DB·서비스·PR #10 pending·배포·병합의 권한은 별도 기존 승인 범위를 따릅니다. 이 문서는 새로운 운영 적용 승인이 아닙니다.
