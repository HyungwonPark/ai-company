# PR #36 수동 Claude 검수 원문 진단

대상은 PR #35의 `1d54d3a0ea5a21c7c2dc588f824c6567231829b4`와 패치 SHA-256 `87bf1835f73f9ff95cd83a0219438fd3c4d4d9bb09199942d83a561b76d9e71b`이다. 이 문서는 비공개 실행 원문을 요약하며, 원문·장부·운영 설치를 변경하지 않는다.

## 확인된 원인

- 저장된 이벤트의 제어 응답 1·1063번은 요청 ID `b8526b1e8549dce772704afdbee308b5-before`·`-after`에 각각 대응한다. 둘 다 `applied={model: claude-opus-5-5, effort: xhigh, ultracode: true}`, `has_errors=false`다. 실제 assistant 응답 116개는 `claude-opus-5-5`였다. 1061번은 `is_api_error_message=true`, `error=rate_limit`인 Claude Code 생성 오류 문구이며 모델 값이 `<synthetic>`이다. 기존 검사는 이 값을 실제 모델 집합에 포함해 `configuration_verified=false`로 만들었다.
- Workflow 시작 575번, 주 호출 결과 741번(`completed`, 비용 누적 $6.9819312), 빈 작업 목록 1056번, 완료 알림 1058번, 후속 결과 1062번(`api_error`, HTTP 429, 비용 누적 $17.3847684) 순서다. 두 결과의 session과 작업 ID가 연결되고, 최종 결과의 자식 수는 종료 조건을 충족한다. 기존 판별기는 **두 결과가 모두 429**일 때만 이 계보를 받아들여 종료·누적 사용량 판정을 놓쳤다. $17.3847684는 최종 결과에서 관측한 누적값이며 두 결과의 합계가 아니다. 현재 예약과 계정은 미정산 `UNKNOWN` 그대로다.
- 35개의 Read 도구 결과가 성공했고 패치의 13개 파일 모두 읽은 사실이 확인됐다. `REVIEW_PROGRESS_JSON` 선언과 최종 범위·판정 보고는 **0개**다. 따라서 완료 인정 파일 0개, 남은 파일 13개를 유지한다. Workflow의 내부 메모에 잠정 지적 6개가 남았으나 신뢰 체크포인트의 확정 지적으로 소급하지 않았다. 내부 메모 원본은 비공개 경로에 해시와 함께 보존했다.

## 수정과 검증

검수기는 거부된 quota 이벤트와 최종 429가 함께 증명된 경우에만 생성 오류 메시지의 `<synthetic>`을 모델 설정 검사에서 제외한다. 주 호출이 정상 종료하고 후속 Workflow만 429가 된 경우도 작업 완료 알림·동일 세션·자식 종료·누적 사용량 단조성을 모두 확인해 quota 종료로 분류한다. 일반 모델 불일치, 알림 누락, 다른 세션·HTTP 상태는 계속 거부한다. 구버전 체크포인트는 원본 재생 결과와 일치하는 경우에만 기존 형식을 유지한다. R36-1~3과 자동 타이머 코드는 변경하지 않았다.

원문 SHA-256: 이벤트 `64a3e151a5694e9069bf62f9d9a88faddcdde35e7ea77c1023df30835c3967b0`, 체크포인트 `3948edc9974b28222d49cbd5f6b67a208a35a4efd4ed15b7dec79f23c84211b3`. 수정 전 관련 회귀는 실패했고, 수정 후 축약 원문 형태와 실제 저장 원문의 **읽기 전용 재생**에서 종료·설정·예상 회복 시각(2026-09-28 07:10 KST)·누적 사용량을 인식했다. 실제 저장 체크포인트는 그대로 재생됐고, 검토 완료 0개였다. 검사 결과와 최종 CI는 해당 코드 커밋에 별도로 연결한다.

## 운영 경계와 다음 수동 재개

이 PR의 수정은 비운영 후보이며 신뢰 경로의 설치본, 전환 해시, 장부, 계정 `UNKNOWN`을 바꾸지 않는다. 적용하려면 네 파일의 새 해시·호환성·백업을 고정한 별도 적용안과 기존 미정산 예약의 증거 기반 1회 정산이 먼저 필요하다. 새 예약 이후 DB를 과거 백업으로 덮어쓰지 않는다. 07:10 KST는 재점검 시각일 뿐 UNKNOWN 해제나 모델 재호출 허가가 아니다. 정확한 대상·계보·현 계정 제한·중복 실행·작업 종료를 다시 확인하고 별도 수동 요청이 있을 때만 다음 검수 한 건을 고려한다.
