## 적용 전 확인 조건

이미 준비된 근거가 있으면 그대로 대조하며, 확인되지 않은 항목만 보완한다. 비밀값과 내부 접속 정보는 공개하지 않는다.

1. **실제로 설치할 릴리스의 Python 3.13.15 환경**에서 worker의 격리 기동과 공용 장부 모의 동작을 확인한다. 실제 모델 호출이나 운영 DB를 사용하는 기동으로 대체하지 않는다. 실패하면 운영 교체를 진행하지 않는다.
2. quota 가드 파일·서비스 변경을 고정한 적용 목록에 포함하고 해시와 실행 경로를 기록한다. 보고한 빈 큐·대기·누락·손상 경계의 결과가 이 가드와 같은 해시인지 확인한다. 구형 모델 호출이 시작되지 않는지 확인한다.
3. 기존 quota 대기 작업의 유무, 보존 대상, 이후 재개 방법을 비공개 기록에 명시한다. 큐를 삭제하거나 task/session을 새로 만들어 대기 상태를 숨기지 않는다.
4. 실제 교체 직전 릴리스·유닛·환경·카탈로그·계정 상태·활성/미정산 호출을 다시 대조한다. 준비 시점과 다르면 교체를 중단하고 차이를 보고한다.

위 조건은 새 제품 기능 요청이나 3.13 CI 전체 확대 요구가 아니다. 실제 적용 후보와 보고된 예행 결과를 연결하는 확인이다. 자료가 이미 충족되면 같은 검사를 불필요하게 반복하지 않는다.
