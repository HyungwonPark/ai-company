## 승인 전에 알아야 할 제한

1. **번역 worker 기동 복구와 실제 번역 처리 복구는 다르다.** 이번 후보를 적용해도 Claude 계정 귀속이 UNKNOWN이면 새 번역·검수·대체 호출은 대기한다. 승인으로 계정을 임의 활성화하지 않는다.
2. 구버전 작업에 재예약 전 실행 스냅샷이 없으면 `unstarted_snapshot_missing_requires_reconciliation`로 조정 대기한다. 모든 과거 작업을 자동으로 재개한다는 약속은 아니다. 원본 자료로 조정하며 작업·시도 기록을 지우지 않는다.
3. **구형 번역 전체 복구는 검증되지 않았다.** 실패 시 목표는 고정한 조건에 따른 PM 유지·번역 중지·quota 가드 유지의 안전 중지다. 파일을 돌려놓았다는 이유로 번역 서비스가 복구됐다고 보고하지 않는다.
4. 동일 사용자 권한의 프로세스가 최종 해시 검사와 실행 사이에 파일을 악의적으로 제자리 변경하는 경우까지 원자적으로 막는 계약은 아니다. 제출한 설치 권한·고정 파일·실행 직전 확인 범위를 유지하며 이를 새 제품 차단 지적으로 확대하지 않는다.
