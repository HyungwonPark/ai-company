# PR 완료 전 Claude 검수 공통 지침

최초 적용: 2026-09-27 · v1.0

사용자가 PR을 마칠 때마다 Claude Opus 5.5·Ultracode 검수를 수행하도록 재확인했습니다. 이 규칙은 앞으로 서버 Codex에 전달하는 모든 PR 완료 지시에 공통 적용하며, 개별 지시서에 빠졌다고 생략하지 않습니다.

기존 제품 [AGENTS.md의 검수 규칙](https://github.com/HyungwonPark/ai-company/blob/3ef6fe7893f4ad2f14f07424d36b991050f46faa/AGENTS.md)을 재확인한 지침입니다. 현재 PR #35의 후속 작업에도 적용합니다. 기존 검수기와 실행 권한·한도·재개 조건을 보존합니다.

## 필수 완료 조건

1. 대상 변경과 CI가 준비되면 구현 세션과 분리된 **실제 Claude Code 검수**를 실행합니다. 모델은 `claude-opus-5-5`, 추론 설정은 `ultracode`를 요청하고 실제 적용 설정의 근거를 확인합니다. 요청 옵션만으로 적용 완료를 주장하거나 다른 모델·모드로 조용히 대체하지 않습니다.
2. 저장소 밖의 신뢰 경로에 설치하고 해시를 확인한 검수기를 사용합니다. 검수 대상 PR 안의 실행 파일로 신뢰한 검수기를 자동 교체하지 않습니다.
3. 정확한 검수 대상 HEAD·base·전체 패치 SHA-256과 전달 근거·검토 범위·판정을 기록합니다. 검토 범위가 부족하거나 실행이 중단됐으면 PASS로 처리하지 않습니다.
4. 지적을 수정하면 변경한 후보에 대한 재검수를 수행합니다. 이전 후보의 PASS를 새 코드에 그대로 붙이지 않습니다. 검수 결과만 기록한 후속 문서 커밋도 실제 검수 대상 커밋과 구별하며 새 HEAD를 검수했다고 쓰지 않습니다.
5. Claude 검수 결과를 확인한 뒤 Work PM 수용 검수에 제출합니다. 이는 실제 PM 판단 품질, Astra 최종 검수, 마스터 계획 확정 또는 배포·병합 승인을 대신하지 않습니다.

## 호출 불가와 중단 처리

- 공용 호출 장부·등록 계정·계정 그룹·전환 기록을 확인한 기존 호출 경로를 사용합니다. 계정 UNKNOWN, 미정산 실행, 사용량 제한, 미연결 상태를 우회하지 않습니다.
- 지금 호출할 수 없으면 구현·CI·독립 정적 검수 결과는 보존하고, **“Claude 검수 대기”**와 구체적인 이유·재개 조건을 기록합니다. 정적 검수를 실제 Claude 검수로 대신하여 전체 검수 완료로 보고하지 않습니다.
- 이미 허용된 PR 검수 호출에 별도 단계별 재승인을 추가하지 않습니다. 새 운영 연결이나 기존 승인 범위를 벗어나는 설정 변경이 필요한 경우에는 해당 변경의 준비된 적용 범위만 확인합니다.
- 같은 HEAD의 중복 호출 방지와 원자적 예약을 유지합니다. 미시작 재시도는 종료 기록과 프롬프트 미전달 증거를 확인하고, 한도 후 재개는 기존 공급자 거절·자식 종료·동일 패치·회복 시각·정산 조건을 충족해야 합니다. 기록을 삭제하거나 빈 커밋으로 중복 호출 제한을 피하지 않습니다.
- 기존 방침대로 임의의 달러·턴 상한을 추가하지 않습니다. 검수기의 실행 시간 30분 제한과 공용 장부 정책은 유지합니다.
- Workflow 도구의 호출 여부와 결과가 최종 판정에 반영됐는지를 구별합니다. Ultracode 적용을 확인했다고 Workflow까지 완료했다고 쓰지 않습니다.

## PR 제출 기록

각 PR 완료 보고와 본문에 다음을 포함합니다.

| 항목 | 기록할 내용 |
| --- | --- |
| 검수 대상 | PR 번호, 검수 HEAD·base, 전체 패치 해시 |
| 모델·설정 | 요청한 모델·추론 설정, 실제 적용 증거와 미확인 항목 |
| 결과 | PASS / REVISE / 검수 대기 / 미완료, 지적·수정·재검수 근거 |
| 범위 | 검토한 범위와 미검토 범위 |
| Workflow | 실제 호출 여부와 결과 반영 여부 |
| 재개 필요 시 | 대기 사유·기존 호출 종료 및 정산·중복 방지·재개 조건 |

인증 정보와 비공개 원시 기록은 공개하지 않고, 공개 가능한 요약·해시·검증 상태만 남깁니다.

## 서버 지침 반영

현재 제품 AGENTS.md의 동일 규칙을 보존하고 작업 브랜치에도 적용되는지 확인하세요. 누락된 브랜치에는 이 정책의 필수 완료 조건과 링크를 작업 지침에 반영합니다. 지침 게시만으로 모든 GitHub PR의 자동 호출 연결이 구현된 것은 아닙니다.

이 문서 게시 자체가 Claude 검수를 수행했다는 뜻은 아닙니다. Work 문서 PR도 같은 상태 구분을 적용하며, 현재 공용 장부·계정 차단 때문에 호출하지 않았다면 그 사실을 보존합니다.
