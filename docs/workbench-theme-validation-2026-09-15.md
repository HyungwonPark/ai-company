# B형 Light·Black 테마 검증

사용자가 선택한 B형을 실제 관리 화면에 구현했다. 로그인은 중앙 패널, 작업 화면은 사이드바 구조를 유지하며 상단에서 `Light`와 `Black`을 선택한다. 현재 상태는 **구현·검증 완료, 공개 화면 반영 승인 대기**다.

- 구현 커밋: `ba499b8cdea7c3628388a7fec994b81286dd181c`
- 최종 검사 커밋: `658bd717a409b13e7ca727ba6e34a25e152182fd`
- 준비한 이미지: `sha256:abe4e6d16fb1b388d0cd7b696b8aa807af501509299349b1ff7b3d6da92fc80f`
- 적용 대상 주소: https://hyungwon.cloud

## 동작

첫 방문에는 기기의 밝기 설정을 따르고, 사용자가 선택하면 해당 브라우저의 `localStorage`에 `ai-company-theme` 값만 저장한다. 저장소 접근이 차단돼도 현재 화면에서 테마를 바꿀 수 있다. 계정·비밀번호·접근 토큰·작업 내용은 이 저장소에 기록하지 않는다.

테마 전환은 CSS 색상과 선택 버튼 상태만 바꾼다. 로그인·비밀번호 변경·PM 대화 입력과 현재 페이지를 다시 만들지 않는다. 새로고침, 화면 이동과 서버 상태 갱신 뒤에도 테마가 유지된다. 경고·오류·실행 상태, 입력란, 대화상자와 모바일 메뉴에 두 색상 체계를 적용했다.

예시와 실제 화면이 같은 폰트를 사용하도록 기존 로컬 폰트를 `/fonts/`로 옮겼다. 외부 폰트 요청은 없다. 공개 화면 셸 캐시에 테마 스크립트와 해당 폰트를 포함하며, 인증 API 응답은 계속 캐시하지 않는다.

## 검증 결과

- [Console UI](https://github.com/HyungwonPark/ai-company/actions/runs/34917940077): 통과. 두 테마의 로그인과 다섯 관리 화면을 데스크톱·모바일에서 확인했다. 기존 인증·비밀번호 변경·계획 확정·승인·복구 상태 표시·입력 보존 검사도 통과했다.
- 새 검증은 선택 저장·새로고침 후 복원, 입력 중 테마 변경, 저장 차단 환경, 기기 테마 변경, 320px 로그인과 360px 관리 화면을 포함한다. 브라우저 오류와 인증 정보의 로컬 저장이 없었다.
- [Python·Android CI](https://github.com/HyungwonPark/ai-company/actions/runs/34917940084): Python 3.11·3.12 각각 회귀 248개와 Android 준비 4개 통과.
- 첫 브라우저 실행에서는 간결해진 제목을 부분 일치로 찾아 두 제목이 선택됐다. 최종 커밋에서 정확한 제목을 찾도록 검사 선택자를 수정했다.
- 로컬 Python 검사에서는 샌드박스가 소켓 생성을 막아 HTTP 서버를 시작하는 13개 검사가 실행되지 못했다. 나머지 235개는 통과했으며, 전체 HTTP 검증 결과는 위 원격 CI로 확인했다.
- 두 테마의 로그인·진행·PM·프로젝트 캡처를 확인했다. 캡처는 Console UI 실행의 `console-screenshots` 아티팩트에 보관한다.

## 적용 승인 경계

관리 화면 컨테이너를 새 이미지로 교체하는 요청은 자동 승인 검토가 거부했다. 사유는 테마 구현 요청만으로 이전 운영 배포 제한이 해제되거나 라이브 적용이 승인됐다고 볼 수 없다는 것이다. 교체 프로세스는 시작되지 않았으며 현재 Compose는 기존 예시 화면 이미지 `sha256:ddb2145c5557e4170c537b825b591d36c318544a28f140c93f59fc89ea31f528`를 유지한다.

승인 대상은 관리 화면 컨테이너의 이미지 교체 한 건이다. 짧은 재접속이 필요할 수 있다. 준비한 절차는 기존 Compose를 백업하고 계정·업무 기록·PR #10 승인 상태와 커플 서비스 프로세스를 대조한다. 공개 파일이 검사한 소스와 일치하지 않거나 접속 검증에 실패하면 이전 이미지로 복구하며 DB를 되감지 않는다.

운영 큐·타이머·격리 설정, PR #10 후보 승인, 병합은 이번 테마 변경에 포함하지 않는다. 실제 마스터의 목표 입력·계획 확정 검증을 수행한 것으로 보고하지 않는다.
